# Как записать демо-GIF

Без GIF ни один пост не зайдёт. На него уйдёт 30-60 минут — но без него остальной маркетинг бесполезен.

---

## Что показать (15-30 секунд)

Сценарий, который продаёт идею **за одну сцену**:

1. **0-3 сек** — экран ноутбука: открыта вкладка `dubtab.app/my-demo`, пустая доска
2. **3-5 сек** — рядом телефон с открытой той же комнатой (можно физически рядом или в split-screen)
3. **5-10 сек** — на ноуте: `Ctrl+C` со скриншота → `Ctrl+V` в доске → **картинка моментально появляется на телефоне**
4. **10-15 сек** — на телефоне: набираешь короткий текст и жмёшь отправить → **появляется на ноуте**
5. **15-22 сек** — на ноуте перетаскиваешь файл в окно → **видно на телефоне**
6. **22-30 сек** — финальный кадр: оба устройства показывают одно и то же содержимое

**Главное:** не объяснять текстом что происходит. Видео должно говорить само.

---

## Чем записывать

### Linux
```bash
# Peek (самый простой, GUI)
sudo apt install peek

# Или ffmpeg напрямую (если нужен контроль)
ffmpeg -f x11grab -framerate 15 -video_size 1280x720 -i :0.0+100,100 \
  -vf "scale=720:-1" -t 30 demo.gif
```

### Windows
- [ScreenToGif](https://www.screentogif.com/) — лучший выбор, есть редактор, оптимизация, обрезка
- Или OBS Studio + конвертация в GIF через ffmpeg

### macOS
- `Cmd+Shift+5` запишет mov → конвертировать через `ffmpeg -i input.mov output.gif`
- Или [Gifox](https://gifox.app/)

### Универсальный совет
Записывай **видео** (mp4/mov), потом конвертируй в GIF. Так легче монтировать. Финальный GIF:

```bash
ffmpeg -i demo.mp4 -vf "fps=12,scale=720:-1:flags=lanczos,split[s0][s1];[s0]palettegen[p];[s1][p]paletteuse" demo.gif
```

## Оптимизация

- **Целевой размер:** до 5 MB (Reddit показывает preview только для GIF <20 MB, но >5 MB начинают тормозить на мобиле)
- **Ширина:** 720px достаточно, 1080 — перебор
- **FPS:** 12-15 хватает для интерфейса
- **Длительность:** 15-30 сек, не больше

Если GIF получается >5 MB:
```bash
gifsicle -O3 --lossy=80 demo.gif -o demo-opt.gif
```

Или используй **WebP** вместо GIF — раза в 3 меньше при том же качестве, GitHub его рендерит:
```bash
ffmpeg -i demo.mp4 -vf "fps=15,scale=720:-1" -loop 0 demo.webp
```

## Если совсем нет времени

Минимально достаточный вариант:
1. Открой `dubtab.app/demo123` на ноуте
2. Открой `dubtab.app/demo123` на телефоне (тот же URL)
3. Запиши 20 секунд: введи текст на ноуте → появилось на телефоне → загрузи фото на телефоне → появилось на ноуте
4. Конвертируй в GIF до 5 MB

Это уровень "достаточно для Reddit". HN/Product Hunt уже требуют чуть больше полировки.
