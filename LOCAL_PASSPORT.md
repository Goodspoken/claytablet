# 📋 Локальный паспорт сервиса — ClayTablet (Serverbook)

Локальный инстанс буфера обмена **ClayTablet**, развернутый на **Serverbook** для совместного доступа устройств внутри локальной сети (LAN/Wi-Fi).

---

## 🌐 Сетевые реквизиты (LAN)

| Сервис | Адрес в локальной сети | Порт | Протокол | Назначение |
| :--- | :--- | :--- | :--- | :--- |
| **Frontend** | `http://192.168.1.2:8505` | `8505` | HTTP | Интерфейс пользователя (Vite + Caddy) |
| **Backend API** | `http://192.168.1.2:8555` | `8555` | HTTP | REST API бэкенд (FastAPI) |
| **WebSocket** | `ws://192.168.1.2:8555/api/ws/rooms/{room_id}` | `8555` | WS | Real-time синхронизация клиентов |

---

## 🛠️ Инфраструктура и хранилище

* **Контейнеризация:** Docker + Docker Compose (запуск от имени пользователя `illz` на Serverbook).
* **Конфигурация:** Использование файла `docker-compose.dev.yml` (запуск без SSL).
* **База данных:** SQLite, файл бд примонтирован на хосте:
  `./data/claytablet.db`
* **Файловое хранилище (изображения, аудио):** папка на хосте:
  `./data/media/`
* **Конфигурационный файл:** `.env.dev`

## ⚙️ Управление сервисом (CLI на Serverbook)

Все команды выполняются из директории проекта на Serverbook (`/home/illz/claytablet/`):

### Запуск стека контейнеров
```bash
docker compose -f docker-compose.dev.yml up -d --build
```

### Остановка стека
```bash
docker compose -f docker-compose.dev.yml down
```

### Перезапуск
```bash
docker compose -f docker-compose.dev.yml restart
```

### Просмотр логов в реальном времени
```bash
docker compose -f docker-compose.dev.yml logs -f --tail=50
```

### Проверка статуса контейнеров
```bash
docker compose -f docker-compose.dev.yml ps
```

## 💡 Особенности и ограничения локальной версии

1. **Без регистрации:**
   Регистрация через внешние OAuth-провайдеры (Google/Yandex) не требуется и отключена в локальном режиме. Доступ к комнатам осуществляется анонимно по короткому URL (например, `http://192.168.1.2:8505/my-room`).

2. **Авто-имена устройств в чате:**
   При первом входе с любого устройства система автоматически детектирует платформу (iOS, Android, Windows, Mac, Linux) и генерирует уникальное имя, например `iOS-4521`, для участия в чате комнаты. Пользователь может изменить имя прямо в чате кнопкой «Изм.».

3. **Авто-очистка комнат (TTL):**
   Каждые 5 минут фоновый процесс сканирует базу данных и удаляет временные комнаты, неактивные более **24 часов** (при этом физические файлы медиа удаляются с диска).

4. **Ограничения (Limits):**
   * Максимальный размер загружаемого файла: **50 MB**
   * Максимум элементов на одну комнату:
     * 50 текстовых записей
     * 30 изображений
     * 30 аудиозаписей
     * 30 прочих файлов
     * 200 сообщений в чате
     * 50 одновременных WebSocket-соединений

## 🔒 Включение HTTPS (SSL) в локальной сети

Для работы функций буфера обмена и микрофона на мобильных устройствах требуется защищенный контекст (HTTPS). По умолчанию в локальной сети используется HTTP из-за ограничений центров сертификации (нельзя выписать доверенный сертификат Let's Encrypt на локальный IP-адрес вроде `192.168.1.2`).

Вы можете включить встроенный самоподписанный SSL в Caddy:

1. Откройте [Caddyfile.dev](file:///home/vscode/claytablet/frontend/Caddyfile.dev) и добавьте директиву `tls internal` в начало блока:
   ```caddy
   :8080 {
       tls internal
       encode gzip
       ...
   ```
2. Перезапустите контейнеры на Serverbook:
   ```bash
   docker compose -f docker-compose.dev.yml down
   docker compose -f docker-compose.dev.yml up -d --build
   ```
3. Зайдите на сайт по адресу `https://192.168.1.2:8505`. Браузер выдаст предупреждение о самоподписанном сертификате. Нажмите **Дополнительно (Advanced) -> Перейти на сайт (Proceed)**.
   
После этого сайт перейдет в режим HTTPS, разблокировав API буфера обмена (`navigator.clipboard`) и микрофон на мобильных устройствах.

## 💻 Использование клиентов с локальным сервером

Для работы с локальным сервером на Serverbook все клиенты должны быть перенаправлены на адрес `http://192.168.1.2:8555` (или `http://192.168.1.2:8505` для веб-интерфейса).

### 1. Консольный клиент (CLI & TUI)
Убедитесь, что исполняемый файл `claytablet` находится в вашей системной папке (например, `/usr/local/bin` или `~/bin`).

* **Первоначальная настройка:**
  Укажите локальный адрес сервера и целевую комнату (например, `111`):
  ```bash
  claytablet config --server http://192.168.1.2:8555 --room 111
  ```
  Конфигурация сохранится в файле `~/.config/claytablet.toml`.

* **Запуск интерактивного терминала (TUI):**
  Интерактивная доска на базе библиотеки Bubble Tea, отображающая содержимое комнаты в реальном времени:
  ```bash
  claytablet tui
  ```

* **Передача данных из терминала:**
  ```bash
  # Отправить текст
  claytablet send "Сообщение из консоли"

  # Перенаправить вывод команды
  cat log.txt | claytablet send

  # Забрать последнее содержимое из буфера в файл
  claytablet copy > local_file.txt
  ```

### 2. Десктопное приложение (Tauri 2)
При запуске приложения откройте **Settings** (Настройки) в меню и укажите адрес локального сервера:
`http://192.168.1.2:8555`

Приложение поддерживает глобальные сочетания клавиш (`Ctrl+Shift+V` / `Ctrl+Shift+C`) и автоматически переносит буфер обмена операционной системы в выбранную комнату на локальном сервере.

### 3. Мобильное приложение (Expo / React Native)
Для подключения мобильного приложения снимите ограничения трафика по HTTP (Cleartext Traffic) в настройках проекта или используйте HTTPS-проксирование, затем укажите адрес в настройках приложения:
`http://192.168.1.2:8555`
