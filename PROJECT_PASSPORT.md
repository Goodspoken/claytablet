## Что это

**ClayTablet** — веб-платформа для мгновенного обмена текстом, изображениями, аудио и сообщениями между устройствами в реальном времени. Построена на концепции «комнат» — изолированных досок с уникальным коротким URL. Синхронизация через WebSocket.

**Целевое применение:** личный инструмент для быстрого обмена данными между компьютерами и телефонами, а также совместная работа с друзьями/коллегами по ссылке.

## Инфраструктура

| Компонент | Детали |
|---|---|
| **Frontend** | React 19, Vite, Tailwind CSS v4 |
| **Backend** | Python 3.11, FastAPI, Uvicorn, WebSocket |
| **Desktop** | Tauri v2 (Rust + WebView), Windows / Linux / macOS |
| **Mobile** | React Native + Expo SDK 52 (в разработке) |
| **CLI** | Go-бинарник `claytablet` |
| **Proxy** | Caddy (автоматический HTTPS, Let's Encrypt) |
| **Container** | Docker + Docker Compose |
| **Storage** | SQLite (SQLAlchemy + Alembic) + файловая система (media volume) |
| **CI/CD** | GitHub Actions |

## API

| Метод | URL | Описание |
|---|---|---|
| `GET` | `/api/health` | Healthcheck |
| `GET` | `/api/claytablet/{room_id}` | Данные комнаты |
| `POST` | `/api/claytablet/{room_id}/text` | Добавить текст |
| `POST` | `/api/claytablet/{room_id}/image` | Загрузить картинку |
| `POST` | `/api/claytablet/{room_id}/audio` | Загрузить аудио |
| `POST` | `/api/claytablet/{room_id}/chat` | Сообщение в чат |
| `WS` | `/api/ws/rooms/{room_id}` | WebSocket канал комнаты |

## Что реализовано ✅

### Функциональность
- [x] Изолированные комнаты по URL (`/{roomId}`)
- [x] Вставка текста, картинок (drag&drop, clipboard), файлов
- [x] **Голосовые сообщения**
- [x] **Canvas / Рисование**
- [x] **Пароль на комнату** (bcrypt)
- [x] Real-time синхронизация через WebSocket
- [x] **Тёмная тема** и полная **i18n (RU/EN)**
- [x] Скачивание в TXT, MD, ZIP
- [x] QR-код для шаринга комнаты
- [x] Система плагинов (Python)
- [x] SSO авторизация (Google, Yandex)
- [x] **Фильтрация на доске** (все / картинки / остальное)
- [x] **Копирование картинок в двух форматах** (как изображение и как текст-ссылка)
- [x] **Отображение списка активных комнат** на главной странице в локальном режиме
- [x] **Быстрое копирование конфигурационной команды для CLI** прямо из шапки комнаты

### Клиенты и утилиты
- [x] **Tauri v2 Desktop** (Windows, Linux, macOS) с поддержкой трея и глобальных горячих клавиш
- [x] **Go CLI-клиент** (`claytablet`) с поддержкой командной строки (`send`, `copy`, `watch`)
- [x] **Интерактивный TUI-клиент** (`claytablet tui`) на базе библиотеки Bubble Tea
- [x] **PWA-версия** с возможностью интеграции в системное меню Share на Android/iOS

### Безопасность, надежность и инфраструктура
- [x] HTTPS (Caddy Let's Encrypt)
- [x] Защита от 500 ошибок при таймаутах сети (SSO)
- [x] Валидация MIME-типов
- [x] Streaming upload (64KB чанки)
- [x] Автоматические миграции БД
- [x] Rate Limiting
- [x] Исправлены докер-хелсчеки (устранены ложные сбои)
- [x] Полный перевод документации проекта на русский язык (`README.ru.md`)
