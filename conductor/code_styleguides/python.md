# Стандарты кодирования для Python

## Форматирование
- Соблюдайте рекомендации PEP 8.
- Используйте 4 пробела для отступа.
- Длина строки не должна превышать 88 символов (стандарт Black).

## Именование
- Переменные и функции: `snake_case`.
- Классы: `PascalCase`.
- Константы: `UPPER_SNAKE_CASE`.

## Типизация
- Обязательно используйте подсказки типов (type hints) для всех параметров функций и возвращаемых значений.
- Используйте Pydantic для валидации данных и управления конфигурацией.

## Тестирование
- Используйте `pytest` для написания тестов.
- Обеспечьте покрытие тестами основной логики и обработку исключений.

## Документация
- Используйте докстринги (Google или NumPy стиль) для всех функций и классов.
- Описывайте аргументы, типы данных и возможные исключения.
