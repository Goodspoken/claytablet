# Стандарты кодирования для TypeScript / React

## Форматирование
- Используйте Prettier для автоматического форматирования.
- Отступ: 2 пробела.
- Точки с запятой: всегда.
- Одинарные кавычки для строк.

## React и компоненты
- Используйте функциональные компоненты и хуки.
- Типизируйте пропсы (props) с помощью интерфейсов (`interface`).
- Файлы компонентов должны иметь расширение `.tsx`.

## Именование
- Компоненты: `PascalCase`.
- Функции и переменные: `camelCase`.
- Интерфейсы: `PascalCase`.

## Типизация
- Избегайте использования `any`. Используйте `unknown`, если тип неизвестен.
- Предпочитайте `interface` вместо `type` для определения структуры объектов.

## Стилизация
- Используйте Tailwind CSS для верстки.
- Применяйте семантическую верстку.
