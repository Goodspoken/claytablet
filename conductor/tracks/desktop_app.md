# Трек: PopyCast Desktop (Windows, Linux, macOS)

**Целевое видение:** Нативное настольное приложение, глубоко интегрированное с операционной системой для мгновенного обмена с буфером обмена ОС.

## Технологии на выбор:
- **Tauri:** Пишется на Rust, рендерит текущий React-фронтенд в WebView. Невероятно легкий (бинарник ~5MB) и потребляет мало ОЗУ по сравнению с Electron.
- **Electron:** Классика, проще в разработке, но потребляет больше ресурсов.

## Идеи для реализации:

1. **Системная интеграция (System Tray):**
   - Приложение висит в трее (около часов).
   - Вывод нативных уведомлений ОС при поступлении нового сообщения в комнату.

2. **Global Hotkeys (Полноценный буфер):**
   - По нажатию `Ctrl+Shift+V` в любом окне появляется виджет поверх всех окон для быстрой вставки из "облачного" буфера.
   - `Ctrl+Shift+C` мгновенно отправляет текст в общую комнату с текущего девайса.

3. **Авто-синхронизация буфера:**
   - Режим (тумблер) "Слушать буфер обмена". Все, что вы копируете в системе, автоматически летит в комнату. Настраиваемые фильтры (например, игнорировать пароли).

4. **Drag & Drop поверх всех окон:**
   - Плавающее "окошко-дропзона" на краю экрана: перетащил туда файл, и он улетел на сервер.
