# Трек: Self-Hosted Mode — Локальный сервер

## Описание
Возможность запустить DubTab на своем сервере или локальном компьютере одной командой.

## Реализовано
- `docker-compose.dev.yml`: Полный стек (Frontend + Backend + Caddy) без SSL на порту 8080.
- `install.sh`: Автоматический скрипт установки (клонирование, создание .env, запуск).
- `.env.dev`: Конфиг для локальной разработки.
- Инструкция в README.md.
