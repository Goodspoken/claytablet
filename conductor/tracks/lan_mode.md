# Трек: Локальная сеть (LAN Mode)

## Описание
Работа внутри Wi-Fi сети без интернета. Телефон и компьютер обмениваются данными напрямую.

## Реализовано
- **Multi-backend support**: Фронтенд умеет переключаться на кастомный URL сервера через настройки.
- **Dynamic URLs**: Все API вызовы и WebSocket используют `getBaseUrl()` из localStorage.
- **QR Code**: Скрипт `install.sh` показывает QR-код для быстрого входа с телефона.
- **Caddy File Server**: Медиафайлы раздаются напрямую, что ускоряет работу в локальной сети.
