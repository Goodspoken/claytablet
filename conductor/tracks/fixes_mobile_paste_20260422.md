# Трек: Кнопка "Вставить" для мобильных устройств
**Статус:** ✅ Завершено
**Дата:** 2026-04-22

## Проблема
На мобильных устройствах не было возможности вставить изображения из буфера обмена на доску, так как стандартное событие `onPaste` не срабатывает при долгом нажатии на пустое пространство (не элементы ввода). 

## Решение
Добавлена специальная кнопка "Вставить из буфера" (ClipboardPaste) в нижнюю панель ввода (`BottomInputBar.tsx`). 

## Детали реализации
1. **Frontend (React):** Использование `navigator.clipboard.read()` для чтения содержимого буфера обмена по клику на кнопку. Поддержка fallback через `navigator.clipboard.readText()` для браузеров без поддержки `read()` (например, Firefox по умолчанию).
2. **i18n:** Добавлены переводы для тултипа кнопки и сообщений об ошибках или отсутствии поддерживаемых данных в буфере.
3. **UX:** Кнопка расположена рядом с кнопкой рисования для удобного доступа.
