# Трек: E2E QA-боты (web / cli / tui / mobile_web / desktop)

**Статус:** ✅ Завершён
**Приоритет:** 🟡 Средний
**Дата создания:** 2026-05-18
**Прогон:** локально devcontainer (Linux), 51 passed / 3 skipped

---

## Цель

Закрыть QA-петлю для всех клиентов ClayTablet одним harness'ом: web-SPA, Go CLI, его же TUI-режим, Expo-web (mobile) и Tauri-desktop. Тесты должны быть автономными (один `pytest`), результаты — единый HTML-отчёт, фолбэки на skip когда зависимости (Android SDK, Xvfb, Tauri build) недоступны.

---

## Что сделано

### Структура `qa/`

```
qa/
├── conftest.py              # общие фикстуры (target_url, api_url, http_get,
│                            #   JSErrorCollector с extra_ignore, page, mobile_page)
├── pytest.ini               # markers: web cli tui mobile_web desktop ...
├── requirements.txt
├── run.sh
│
├── web/         (29 тестов) Playwright против React SPA
├── cli/         (13 тестов) subprocess против `claytab` Go binary
├── tui/         (3 теста)   pexpect PTY-драйвер `claytab tui`
├── mobile_web/  (3 теста)   Playwright против `expo start --web`
└── desktop/     (6 тестов)  Playwright против desktop/dist + смоук Tauri бинарника
```

### Покрытие

| Набор | Что проверяется |
|---|---|
| **web** | загрузка главной, SEO (robots, sitemap, og-теги, canonical, twitter card), мобильный viewport 390×844, регрессия `/_terms` → `/terms`, AuthModal с Escape, бренд в футере, базовые API ручки (`/api/claytablet/{room}`, `/api/auth/me`, `/api/claytablet/rooms/public|system`, rate-limit) |
| **cli** | `--help`, неизвестная команда, `send` без сервера, `me`/`room` без конфига, `config` → `~/.config/claytablet.toml`, persistence, send/ls/clear/pipe-stdin/big-text против реального бэкенда |
| **tui** | `claytab tui` стартует и держится живым, рендерит non-empty экран, корректно завершается на `q` |
| **mobile_web** | Expo web-бандл грузится через Metro, body не пустой, рендерит UI-маркеры приложения (RU/EN); auto-skip если :8081 не отвечает |
| **desktop** | desktop/dist индекс отдаётся, title не дефолтный «Tauri + React + Typescript»; Tauri-бинарник — `needs_xvfb`/skip без DISPLAY; WebDriver через `tauri-driver` — заготовка |

### Запуск

```bash
cd qa
./run.sh                                  # установит deps + всё прогонит
pytest -m cli                             # только CLI
pytest -m "web or cli"                    # комбо
TARGET_URL=https://claytablet.online pytest -m web   # против прода
```

## Найденные и исправленные баги

### 🔴 Критичное (нашёл бот)

**B1. CLI бинарник `cli/claytab` устарел и шёл по `/api/claytablet/...` вместо `/api/claytablet/...`**
Source-код в `cli/api/client.go:129` был корректен, но скомпилированный бинарник в репо относился к более старой ветке. Все вызовы `send/ls/clear` возвращали 404.

**Что сделано:** Пересобрал из исходников. Заодно починил compile-error в [cli/cmd/logout.go:17](cli/cmd/logout.go#L17) — неиспользуемая переменная `token`, из-за которой `go build` падал.

### 🟡 Major

**B2. AuthModal не реагировал на Escape**
В [frontend/src/components/AuthModal.tsx](frontend/src/components/AuthModal.tsx) не было обработчика `keydown`. Добавлен `useEffect` с `window.addEventListener('keydown', ...)`.

**B3. desktop/index.html и desktop/dist/index.html — дефолтный шаблон Tauri**
`<title>Tauri + React + Typescript</title>` → `<title>ClayTablet Desktop</title>`. Полноценный ребренд десктоп-обёртки оставлен как отдельный TODO — там ещё `vite.svg` фавикон и заглушечный Cargo namespace.

### Не баг, но улучшение

- Расширил `JSErrorCollector` в [qa/conftest.py:25-65](qa/conftest.py#L25-L65) — теперь поддерживает `extra_ignore`, чтобы desktop-suite не падал на `pageerror` от Tauri-only API в браузере без Tauri-runtime.

## Что НЕ покрыто (и почему)

| Цель | Причина |
|---|---|
| **Нативный Android** | Нужен Android SDK + emulator + Appium. В devcontainer не запустится. Скелет можно добавить позже как `qa/android/` с Appium-Python-Client. |
| **Tauri E2E через WebDriver** | Нужен `tauri-driver` + `webkit2gtk-driver` + Xvfb. Маркер `needs_xvfb` зарезервирован, тест-заглушка с инструкцией лежит в [qa/desktop/test_desktop_binary.py](qa/desktop/test_desktop_binary.py). |
| **iOS** | Mac + Xcode required. Не приоритет. |

## Зависимости для прогона

Перед запуском нужны:
- `pip install -r qa/requirements.txt` (playwright, pytest-playwright, pytest-html, pexpect, requests)
- `playwright install chromium`
- системные либы для Chromium (`apt install libatk1.0-0 libnss3 libxkbcommon0 libgbm1 …` — `playwright install --with-deps` тоже подходит, но требует sudo)
- Для CLI/TUI наборов: пересобранный `cli/claytab` (`cd cli && go build -o claytab .`) — Go 1.24+
- Для mobile_web: `cd mobile && npm install && npm run web` отдельным процессом
- Для desktop (frontend): `cd desktop && npm install && npm run build`
- Для desktop binary launch: `cd desktop && npm run tauri build` + DISPLAY/Xvfb
