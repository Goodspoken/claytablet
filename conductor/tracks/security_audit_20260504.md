## Цель
Провести полный аудит кодовой базы PopyCast (ClayTablet) перед переходом к разработке десктопного приложения и Open Source релизу. Устранить критические уязвимости и улучшить UX обработки ошибок.

## Выполненные работы

### 🔴 Безопасность (Critical)
1.  **JWT Leakage:** Устранена утечка токена в URL при OAuth редиректе (`auth.py`). Теперь токен передается только через `HttpOnly` куки.
2.  **Weak Secret Protection:** Добавлена обязательная проверка длины и наличия `JWT_SECRET`. Приложение не запустится с небезопасным ключом.
3.  **SVG XSS:** Убран авто-рендеринг `.svg` файлов через `<img>` в карточках для предотвращения XSS атак.
4.  **Read-Only Bypass:** Исправлена дыра в `POST /settings`, позволявшая гостям отключать режим "Только чтение".
5.  **Blocked Extensions:** Введен черный список опасных расширений (`.php`, `.py`, `.sh`, `.exe` и др.) для всех загрузок.

### 🟡 Стабильность и Качество
1.  **Refactoring Uploads:** Логика загрузки файлов полностью дедуплицирована и перенесена в единый защищенный хендлер `_upload_media`.
2.  **File Sizes:** Исправлено сохранение `file_size` для изображений и аудио (ранее сохранялось только для документов).
3.  **Race Conditions:** Замена небезопасных проверок `os.path.exists` на атомарные `try/except` при удалении файлов.
4.  **Sentry Privacy:** Отключена отправка PII (Personal Identifiable Information: IP, Cookies) в Sentry для соответствия GDPR.

### 🔵 UX Улучшения
1.  **Error Feedback:** Добавлена специфичная обработка ошибки 403 (Forbidden). Теперь пользователь видит сообщение "Доска в режиме «только чтение»" вместо общего "Ошибка загрузки".
2.  **Magic Numbers:** Все захардкоженные лимиты (50 текстов, 30 файлов, 200 чатов) вынесены в константы и синхронизированы с API Config.
