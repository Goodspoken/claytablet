# Трек: Улучшения, Оптимизации и Стабильность

**Целевое видение:** Сделать приложение невероятно быстрым, надежным и готовым к большой нагрузке, а также закрыть оставшиеся хвосты по функционалу.

## Идеи для реализации:

1. **Переезд на БД (SQLite / PostgreSQL):**
   - Сейчас все хранится in-memory. Рестарт сервера убивает метаданные. Обязательный переезд на БД через ORM (SQLAlchemy).
   
2. **Завершение i18n и Тёмной темы:**
   - Внедрить `i18next` для полноценной локализации.
   - Настроить Tailwind для глубокой тёмной темы, реагирующей на системные настройки.

3. **UX Оптимизации:**
   - Виртуализация (React Virtualized) сетки `CardGrid` для комнат с >500 элементами.
   - Ленивая подгрузка изображений (IntersectionObserver) с блюром-превью (blurhash), пока загружаются.
   - PWA (Progressive Web App): service worker для кеширования оффлайн-состояния, установка на главный экран смартфона из браузера.

4. **Оптимизация Бэкенда:**
   - Упаковка/сжатие передаваемых по WS данных (msgpack вместо JSON).
   - Rate limiting и throttling (FastAPI-Limiter), чтобы защититься от спама и DDoS.
   - Рефакторинг `Board.tsx` (распил "чистого контекста" React API Context или Zustand для стейт-менеджмента).
