# Трек: Глобальная авторизация и управление профилем

**Целевое видение:** Отказ от полностью анонимного/эфемерного режима (или дополнение его) системой аккаунтов. Это позволит пользователям сохранять свои комнаты и устройства.

## Идеи для реализации:

1. **Регистрация / Вход (JWT / OAuth):**
   - Возможность зайти через Google/GitHub или по Email/Паролю.
   - Использование JWT-токенов в куках (httpOnly) для поддержания сессии.

2. **Персональные комнаты и "Мои доски":**
   - Вместо того чтобы терять ссылку на комнату, все комнаты пользователя отображаются в его Dashboard.
   - Пользователь может делать комнаты «Публичными» (по ссылке), «Приватными» (только для себя) или «Shared» (доступ только для других зарегистрированных друзей).
   - Закрепление сообщений/папок внутри своей комнаты.

3. **Связь устройств (Device Pairing):**
   - Вместо шаринга ссылки, пользователь логинится на телефоне и ПК — у них появляется общий "Глобальный буфер обмена", который не нужно каждый раз искать.

**Архитектура:** Бэкенд нужно перевести на персистентную базу данных (PostgreSQL или SQLite) для хранения пользователей и их комнат.
