# Исходная концепция

**PopyCast** (ранее Clipboard) — это полнофункциональное веб-приложение реального времени, которое позволяет пользователям обмениваться текстом, изображениями, аудио и сообщениями в чате во временных (эфемерных) «комнатах».

## Целевая аудитория
- Пользователи, которым нужен быстрый, анонимный и беспрепятственный способ передачи данных между устройствами (например, с мобильного на десктоп, от коллеги к коллеге).
- Команды, которым нужно временное рабочее пространство для мозгового штурма или обмена ресурсами без постоянного хранения.

## Ключевые особенности
- **Интерфейс в стиле мессенджера:** Нижняя панель ввода с поддержкой текста, голосовых сообщений и рисования (Canvas).
- **Голосовые сообщения:** Запись прямо в браузере через MediaRecorder, кросс-браузерная поддержка (Chrome, Firefox, Safari/iOS).
- **Canvas / Рисование:** Встроенный холст с выбором цвета, толщины, ластика. Сохраняется как изображение в комнату.
- **Эфемерные комнаты:** Временные комнаты с уникальным URL. Поддерживаются открытые и защищённые паролем комнаты.
- **Синхронизация в реальном времени:** WebSocket с ping/pong heartbeat и exponential backoff переподключением.
- **Поддержка мультимедиа:** Текст, изображения, аудио — через вставку (Ctrl+V), drag & drop или кнопки ввода.
- **Автоматическая очистка:** Настраиваемый TTL (10мин / 1ч / 24ч / 7дней / навсегда).

## Цели проекта
- Предоставить отзывчивый и интуитивно понятный пользовательский интерфейс с использованием современных React и Tailwind CSS.
- Обеспечить высокую производительность и надежность на бэкенде с использованием асинхронного Python и FastAPI.
- Облегчить простое развертывание в контейнерах с помощью Docker Compose.
