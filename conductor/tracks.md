- [ ] **Трек: Open Source — GitHub, Комьюнити и Экосистема**
  *Приоритет: 🔵 Стратегический*

  *Публикация на GitHub как open-source (MIT). Цель — живое комьюнити вокруг одного ядра.*

  **Стратегия "One Core, Open Ecosystem":**
  > Всё бесплатно и открыто. Улучшения — через Pull Request в main. Плагины — через Plugin API.

  **Шаги запуска репо:**
  1. `README.md` — красивый баннер, GIF-демо, quick start за 1 команду.
  2. `CONTRIBUTING.md` — как участвовать, код-стайл, процесс PR.
  3. `LICENSE` — **MIT** (максимально открытая).
  4. `.github/ISSUE_TEMPLATE/` — шаблоны bug report и feature request.
  5. `.github/workflows/` — GitHub Actions: lint + pytest при каждом PR.
  6. Topics: `clipboard`, `self-hosted`, `realtime`, `fastapi`, `react`, `websocket`.

  **Модель участия:**
  - Issues → предложения и баги от комьюнити.
  - PR → вклад в код (ревью + мёрдж в main).
  - Discussions → идеи, use cases, вопросы.
  - `good first issue` лейбл — для новичков.
  - GitHub Sponsors — поддержка разработки (опционально).

  **Plugin API (будущее):** хук-система (`on_text_added`, `on_room_created`) + фронтенд-слоты для виджетов. Позволит добавлять темы, переводы, интеграции без форка ядра.

  **Почему не форки:** форки разбивают комьюнити. Один репо с хорошим governance — как Vite, n8n, Shadcn.
