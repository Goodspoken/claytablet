# Спецификация: Редизайн UI (Header и поле ввода)

## Обзор
Цель трека — разгрузить верхнюю панель (Header), сделать интерфейс более похожим на современные мессенджеры и логически сгруппировать функции управления комнатой.

## Ключевые изменения

### 1. Нижняя панель ввода (Messenger-style)
- Поле ввода текста переносится из Header вниз экрана.
- В эту же панель добавляются кнопки: **Голосовое сообщение (микрофон)** и **Холст/Рисование**.
- Панель прилипает к низу экрана и всегда доступна.

### 2. Меню "Поделиться" (Share)
- Консолидация функций шеринга в одну кнопку/меню в Header.
- Внутри:
  - Показать QR-код.
  - Скопировать ссылку.
  - Кнопки быстрого шеринга (Telegram, WhatsApp и т.д. через Web Share API или прямые ссылки).

### 3. Меню "Управление" (Management)
- Новая кнопка/выпадающее меню в Header.
- Внутри:
  - Создать новую комнату.
  - История (недавние комнаты).
  - *Возможно:* Переход к настройкам.

### 4. Настройки (Settings)
- Модальное окно настроек остается (TTL, управление паролем, очистка доски).
- Кнопка вызова настроек остается в Header (или переносится в меню "Управление").

### 5. Индикаторы статуса в Header
- Возле ID комнаты отображаются наглядные иконки:
  - `🔒` Замок (если комната защищена паролем).
  - `⏱️` Иконка таймера/часов (показывает TTL или обратный отсчет).

### 6. Адаптивность (Mobile-first)
- На мобильных устройствах Header должен быть максимально компактным (только иконки без подписей).
- Нижняя панель ввода должна корректно работать с экранной клавиатурой.

## Критерии приемки
- Поле ввода текста исчезло из Header и находится внизу.
- Кнопки микрофона и холста находятся рядом с полем ввода.
- Меню шеринга объединяет QR, копирование и соцсети.
- В Header появились иконки статуса (замок, таймер).
- Интерфейс корректно отображается на мобильных экранах.
