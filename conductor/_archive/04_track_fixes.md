# Фиксы медиа, UX и WebSocket (2026-04-19)

## Выполнено:
- **Media & UX**:
  - Полностью исправлен Canvas (отмасштабированы координаты, убран ghosting при закрытии модалки).
  - Настроена кросс-совместимая запись аудио. Добавлено определение нужного MIME формата (Safari не поддерживает `audio/webm`, теперь автоматически используется лучший доступный вариант `.m4a`/`mp4`).
  - Исправлена работа "Поделиться" для аудио-карточек в браузере (нативно API Share или toast об успехе).
  - Drag & Drop оверлей теперь разрешает закидывать любые медиа (добавлено аудио).
  - При запрете доступа к микрофону теперь выводится юзер-френдли Toast.

- **WebSocket и backend**:
  - На стороне фронтенда добавлен *Debounce (~300мс)* на сообщения синхронизации.
  - Настроен Heartbeat (Ping/Pong) — клиент посылает `ping` раз в 30 секунд, бэкенд отвечает `pong`. Это предотвращает обрыв WebSocket соединения роутерами и прокси (Nginx).
  - Поправлена конфигурация CORS (`allow_origin_regex=".*"`) для корректной работы с `allow_credentials=True`.
