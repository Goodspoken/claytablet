# Промпт для агента Grandfather: Деплой Caddy и Let's Encrypt

> **Для пользователя:** Передай этот файл или его содержимое агенту Grandfather, который работает на хост-машине с доступом к PowerShell и SSH ключам.

---

Привет! У нас есть готовые изменения в проекте PopyCast (бывший Clipboard), которые нужно задеплоить на наш VPS. Мы перешли с архитектуры Nginx на Caddy, чтобы автоматически получить SSL-сертификат от Let's Encrypt для домена popycast.duckdns.org (IP 109.120.134.188). 

Все конфигурации в проекте уже обновлены. Твоя задача — настроить firewall на сервере и запустить скрипт деплоя. 

У тебя есть доступ к хосту (Windows). Подключение к серверу осуществляется по SSH (`admin@109.120.134.188` порт `2202`).

Выполни следующие 2 шага строго по порядку:

### Шаг 1. Настройка Firewall (UFW) на VPS
Let's Encrypt и Caddy требуют открытых портов 80 (HTTP) и 443 (HTTPS).
1. Подключись к серверу по SSH (`ssh -p 2202 admin@109.120.134.188`).
2. Проверь статус ufw: `sudo ufw status`.
3. Разреши порты 80 и 443 TCP командами:
   `sudo ufw allow 80/tcp`
   `sudo ufw allow 443/tcp`
   `sudo ufw reload`
4. Убедись, что порты добавлены, и отключись от сервера.

### Шаг 2. Деплой текущего кода
1. Убедись, что находишься в корневой папке проекта `clip`.
2. Запусти локальный PowerShell скрипт деплоя: `.\deploy.ps1`.
Этот скрипт сам загрузит все измененные файлы (включая новые Dockerfile, Caddyfile и docker-compose.yml) на сервер в папку `/opt/clipboard` и выполнит пересборку Docker контейнеров.

Обязательно дождись окончания скрипта и логируй любые возникшие ошибки. Если деплой прошел успешно, проверь доступность приложения по ссылке: `https://popycast.duckdns.org`.
