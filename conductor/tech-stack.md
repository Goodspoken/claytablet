# Технологический стек проекта

## Фронтенд (Frontend)
- **Библиотека:** React 19 (SPA)
- **Язык:** TypeScript
- **Стилизация:** Tailwind CSS (v4)
- **Сборка:** Vite
- **Дополнительные пакеты:**
  - `axios`: Для HTTP-запросов к API.
  - `react-router-dom`: Для навигации в приложении.
  - `lucide-react`: Иконки.
  - `qrcode.react`: Генерация QR-кодов.

## Бэкенд (Backend)
- **Фреймворк:** FastAPI
- **Язык:** Python 3.x
- **ASGI-сервер:** Uvicorn
- **Валидация данных:** Pydantic
- **Обработка данных форм:** Python Multipart (для загрузки файлов)

## Инфраструктура и развертывание
- **Контейнеризация:** Docker и Docker Compose
- **Реалтайм-связь:** WebSockets (интегрировано в FastAPI)
- **Хранение данных:** Временное (In-memory и локальная файловая система для медиафайлов)
